## Features

- View coding activity and time tracked by WakaTime
- OAuth login support for WakaTime
- Clean mobile-first interface (M3 Design)
- Light and dark theme support
- User profile and account statistics
- Daily, weekly, monthly insights
- Sticky notification about today's activity

## Getting Started

### Prerequisites

- Node.js
- npm, pnpm, bun, or yarn
- Expo CLI (optional)

### Installation

```bash
git clone https://github.com/infinotiver/wakadash.git
cd wakadash
npm install
```

### Run

```bash
npm start
```

For specific platforms:

```bash
npm run android
npm run ios
npm run web
```

## Configuration

1. Generate a WakaTime API key from your WakaTime account settings.
2. Open WakaDash.
3. Enter your API key in the app.
4. Start exploring your coding statistics.
